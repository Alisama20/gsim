Reproducer for a Palace 2D boundary-mode question: Z_PV of a coplanar-strip line with finite-conductivity conductors.
Geometry: the metal-only electrode of Baehr-Jones et al., Opt. Express 20(11) 12014 (2012): two Al strips 2 um thick, 5 um gap, sigma = 1e7 S/m, on oxide over Si.
Folders: lossy_1GHz, lossy_10GHz (Conductivity boundary, Thickness 2 um) and pec_conductors_10GHz (same mesh, conductors as PEC).
Each folder: config.json, palace.msh, and the outputs mode-Z.csv, mode-kn.csv, palace.log. Palace build e1bdf9b7.
